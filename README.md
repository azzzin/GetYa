# 겟야! Get-Ya!

검토용 공유 주소는 https://azzzin.github.io/GetYa/ 입니다. `?version=mvp`는 이전 MVP 비교용입니다.

전시 노트북에는 이 버전의 프로젝트를 복사하고 Node.js 22를 설치한 뒤, 프로젝트 폴더에서 `npm ci`를 한 번 실행하세요. 전시 당일에는 `npm run dev -- --port 5173 --strictPort`로 실행한 뒤 **항상 같은 브라우저 프로필**에서 http://127.0.0.1:5173/ 을 사용하세요. 준비가 끝난 뒤에는 오프라인에서도 플레이할 수 있습니다. Mac은 **게임 실행.command**로 열어도 됩니다.

전시 응답은 해당 노트북의 브라우저에 저장됩니다. 비공개 창이나 브라우저 데이터 삭제를 피하고, 운영자가 http://127.0.0.1:5173/?scene=32:2441&operator=1 에서 JSON으로 백업할 수 있습니다. 다른 관람객에게는 공개에 동의한 서술형 후기와 유저네임이 표시됩니다. 공개 주소에서는 응답을 저장하지 않고 현재 화면에서만 제출 결과를 체험합니다.

Figma 원본을 바탕으로 만든 React + Vite 선택형 웹게임 MVP입니다.

## 실행하기

Finder에서 **게임 실행.command** 파일을 두 번 클릭하면 브라우저에서 게임이 열립니다. 실행 중인 터미널 창은 열어 두세요. 종료할 때는 터미널에서 Control+C를 누르면 됩니다. 이미 실행 중이라면 브라우저에서 http://127.0.0.1:5173 을 여세요.

현재 Mac에서 별도 Node.js 설치 없이 실행하도록 `.tools/node`에 검증된 공식 Node.js 실행 파일을 준비했습니다. 이 로컬 실행 도구는 Git에 포함하지 않습니다. 다른 컴퓨터에서는 Node.js 22.12 이상을 설치한 뒤 `npm install`, `npm run dev`로 실행합니다.

## 플레이 방법

1. 닉네임은 선택 입력입니다. START를 누릅니다.
2. 진로 또는 친구 문을 선택합니다.
3. 삼각형 버튼으로 대사를 넘기고, 두 카드 중 하나를 선택합니다.
4. 엔딩에서 다시 하기를 누르면 선택 기록이 초기화됩니다. 상단 홈 버튼도 처음으로 돌아갑니다.

다음 대사 화면에서는 Enter 또는 Space 키도 사용할 수 있습니다. Tab 키로 버튼을 이동할 수 있습니다. 화면은 Figma의 16:9 비율을 유지합니다. 세로 휴대폰에서는 가로로 돌리면 글자가 더 크게 보입니다.

## 반영한 내용

- 원본 Figma 화면 42개 중 중복 시작·튜토리얼을 공유하여 플레이 화면 40개 구성
- 실제 배경·캐릭터·로고·버튼·상황 이미지 사용, 바이트가 동일한 다운로드는 43개 파일로 공유
- Mona12 TTF 일반·굵게만 사용. Inter와 Noto Sans KR은 사용하지 않음
- 친구·진로 두 이야기, 선택에 따른 다른 장면, 공통 장면으로 합류, 엔딩, 처음으로
- 진행 표시는 선택 단계에 따라 1/4 → 2/4 → 3/4 → 4/4로 변경
- Figma에 남아 있는 일부 회색 LOGO 임시 영역은 원본대로 유지

## 나중에 추가할 자료

**배경음악·효과음:** 현재는 무음입니다. `public/audio/`에 파일을 넣고 `src/data/settings.js`의 `audio.bgm`, `audio.click`에 `/audio/파일명.mp3`처럼 경로를 지정합니다. 경로를 비워 두면 누락 파일을 요청하지 않습니다. 연결 후 START 클릭으로 BGM이 반복 재생되며 상단 소리 켜기·끄기로 제어합니다.

**후기 주소:** 같은 설정 파일의 `reviewUrl`을 지정하면 후기 남기기에서 새 탭으로 열립니다. 현재는 준비 중 안내를 표시합니다.

**pw 입력란:** 입력할 수 있지만 실제 로그인·계정 기능은 없습니다. 입력값을 서버로 전송하거나 저장하지 않으며 시작 화면을 떠날 때 지워집니다. 닉네임과 선택도 브라우저 새로고침 시 초기화됩니다.

## 디자인 수정과 반영

현재 웹은 Figma 디자인을 가져와 만든 로컬 코드입니다. **Figma 파일을 수정해도 웹이 자동으로 바뀌지는 않습니다.** Figma에서 화면을 수정한 뒤 변경한 프레임 링크와 내용을 이 채팅에 알려 주세요. 변경 프레임의 디자인·이미지를 다시 읽고, 웹의 해당 부분을 수정한 뒤 화면과 게임 동작을 확인하는 순서로 반영합니다. 공개 배포된 웹사이트에는 수정 후 재배포도 필요합니다.

호버·클릭 같은 상태는 같은 버튼/문의 기본·호버·클릭 상태를 나란히 보여주거나 컴포넌트 variant로 구분해 주면 전달하기 쉽습니다. 현재 추가한 문 열림과 도트 다음 화살표는 웹 코드에서 적용한 것으로 Figma 원본에는 반영하지 않았습니다. 폰트는 모든 화면에서 Mona12를 유지합니다.

선택지의 문은 기본적으로 둘 다 닫히며 호버·키보드 포커스·터치/클릭 시 열립니다. 선택 후 열린 모습을 0.18초 표시한 뒤 다음 장면으로 이동합니다. PNG의 투명 여백을 제외한 실제 검정 문틀을 기준으로 좌측 위치와 가로·세로 크기를 맞춥니다. 원본 이미지는 변경하지 않습니다. 현재 입력 시작점은 1920×1080 기준 x830입니다(직전 x790에서 오른쪽 40px 이동).

진행 표시는 #B9E84C의 계단형 도트 모양입니다. 다음 삼각형은 실제 아이콘 자체가 버튼이며, 중심 기준 160×112 디자인 픽셀의 클릭 영역을 갖습니다. 진로·친구 고민 소개 네 화면은 말풍선 본문 안에서 대사를 왼쪽 정렬하고 세로 중앙에 배치합니다.

## 다른 사람에게 공유하기

### GitHub Pages

GitHub Pages로도 배포할 수 있도록 상대 경로와 `.github/workflows/deploy-pages.yml`을 준비했습니다. 저장소의 `main` 브랜치에 코드를 올리고 Settings → Pages → Source에서 **GitHub Actions**를 선택하면 이후 main에 반영한 코드가 자동 빌드·배포됩니다. GitHub Free 계정에서는 공개 저장소를 사용합니다. 저장소 이름이 GetYa라면 일반적인 공유 주소는 `https://사용자명.github.io/GetYa/`입니다. 실제 주소는 배포 완료 후 Settings → Pages에서 확인합니다.

현재는 로컬 설정만 준비했습니다. GitHub 저장소 연결·업로드·실제 배포는 아직 진행하지 않았습니다. `.tools`, `node_modules`, 검증 스크린샷, 폰트 원본 전체 폴더는 업로드할 필요가 없습니다. 실행에 필요한 폰트·라이선스는 `public/fonts`에 포함되어 있습니다.

### 파일 업로드 방식

현재 `127.0.0.1:5173` 주소는 이 컴퓨터의 개발 서버 주소입니다. 다른 사람에게 이 주소를 보내면 같은 게임에 접속할 수 없습니다.

코드 없이 공유하려면 Netlify Drop(https://app.netlify.com/drop)에 빌드 결과인 `dist` 폴더 또는 `GetYa-share.zip`을 업로드하는 방법을 사용할 수 있습니다. 제공되는 웹 주소를 다른 사람에게 전달하면 각자의 기기에서 플레이할 수 있습니다. 프로젝트 원본 폴더 대신 빌드 결과만 업로드하세요. 이 작업에서는 공개 업로드를 진행하지 않았습니다.

웹을 수정한 뒤에는 `npm run build`로 `dist`를 갱신해야 합니다. 압축 파일은 생성 당시의 버전이므로 수정 이후에는 다시 만들어야 합니다. 이미 올린 사이트를 갱신할 때는 해당 사이트의 Deploys 화면에 새 빌드 결과를 업로드하세요.

이 방식은 각자 독립적으로 게임을 플레이하는 공유입니다. 여러 사람이 같은 장면이나 선택을 실시간으로 함께 조작하는 기능은 현재 MVP에 없습니다.

현재 문 정렬에는 추가 SVG가 필요하지 않습니다. 나중에 벡터 원본으로 교체할 경우 `public/assets/doors/door-closed.svg`, `public/assets/doors/door-open.svg`로 전달하면 됩니다. 두 파일의 프레임/아트보드 크기, 문틀 좌표, 문틀 크기를 동일하게 맞추면 열린 문짝만 바뀌는 효과를 정확하게 구현할 수 있습니다.

## 개발 파일 안내

| 파일 | 역할 |
| --- | --- |
| `src/data/story.js` | 장면 연결, 선택 대상, 분기·합류, 초기화 |
| `src/data/content.json` | Figma 원본 대사·선택지·버튼 글자 |
| `src/data/layouts.json` | 원본 Figma 레이어 ID·배치·로컬 이미지 참조 |
| `src/figma.css` | 원본 배치에서 변환한 일반 CSS, Tailwind 미사용 |
| `src/data/settings.js` | 음원·후기 주소 설정 |
| `src/audio.js` | 음원 재생·음소거·탭 비활성 시 정지·오류 안내 |
| `design/figma-context.json` | 확인한 원본 디자인 응답 기록 |

프레임 배치·이름·대사에 따라 MVP 장면 연결을 구성했습니다. 별도 프로토타입 링크 동작을 검증한 결과는 아니므로 원작에서 의도한 연결이 다르면 `story.js`에서 수정할 수 있습니다.

`npm test`로 모든 장면 연결·합류·초기화·이미지·폰트 참조를 확인하고, `npm run build`로 배포용 `dist/`를 만듭니다. `npm run test:browser`는 Playwright 브라우저 설치가 필요합니다. 설치된 Chrome을 사용하려면 `GETYA_CHROME_PATH` 환경 변수에 실행 파일 경로를 지정합니다. 테스트는 두 이야기의 16개 선택 조합을 끝까지 실행하고 `artifacts/screenshots/`에 화면을 저장합니다.

Mona 폰트의 저작권·라이선스는 `public/fonts/LICENSE/`에 동봉했습니다.
